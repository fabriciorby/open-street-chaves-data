# Street Chaves 1.5A — original game data

This repository holds the original **Street Chaves — O Lutador da Vila**
(version 1.5A, 2003–2004) by **CyberGamba**, exactly as it was distributed:
`Chaves.exe` and its data folders, plus the author's own `STREET CHAVES.txt`,
which states that the game is freeware and may not be sold
("ESTE JOGO É FREEWARE ... PROIBIDO SER COMERCIALIZADO").

It exists only so that the web build of
[open-street-chaves](https://github.com/fabriciorby/open-street-chaves), a
free reimplementation of the game engine, can run in the browser without
asking players for their own copy. Nothing here is sold or modified. The
characters belong to their respective owners.

If you hold rights over this material and want it taken down, open an issue
or contact the repository owner: it will be removed on request.
